# 概念学习资料生成器（concept-learning-kit）

把一个陌生的概念变成一份"能自己站得住"的学习资料：不是复述 AI 的回答，而是按固定的学习框架组织信息、标注可核查的来源、暴露易混淆点，并留下自测题供日后检验。

## 适用场景

- 学习一个新概念（技术、方法论、学科名词均可），需要一份结构化、可回看的学习笔记；
- 需要向他人讲清楚某个概念，想先梳理出"解释—机制—案例—边界"的完整链条；
- 积累个人概念库：每学一个概念就多一份材料，最终形成知识图谱（概念关系说明）。

不适用于：需要精确计算或实时数据的查询（本 Skill 产出的是解释性材料，不是实时答案）。

## 输入信息

调用本 Skill 时，至少提供：

1. **概念名称**（必需）：如"Agent"、"大模型的上下文"。
2. **学习深度**（可选，默认"入门+机制"）：入门级 / 入门+机制 / 深入源码级。
3. **已知背景**（可选）：学习者已了解哪些相关概念，用于校准材料的起点，避免把已会的内容再讲一遍。
4. **目标受众**（可选，默认"自己"）：写给自己的笔记与写给他人的讲解，措辞和详略不同。
5. **输出文件名**（可选，默认按概念的英文短名生成，如 `llm-context.html`）。

## 生成步骤

1. **界定概念**：明确概念的定义、外延和它"不是什么"，先写一句自己的话概括（不许照搬任何来源的原句）。
2. **设定学习目标**：列出 3–5 条"学完后应能做什么"的目标（可检验的行为，如"能解释 X 和 Y 的区别"）。
3. **提出核心问题**：围绕概念提出 3–5 个驱动性问题，后续内容必须逐一回答这些问题。
4. **拆解核心机制/组成**：把概念拆成 3–5 个关键机制或组成部分，逐一解释，并说明它们如何协作。
5. **构造应用案例**：设计一个具体、贴近真实场景的应用案例，走一遍概念在实际中如何工作。
6. **辨析易混淆点**：列出 2–4 个最容易混淆的近邻概念或误用场景，说明区别与判断标准（即概念的"使用边界"）。
7. **编写自测题**：出 3–5 道自测题（含简答与辨析题），并在文末附上要点提示（不是完整答案，防止背答案）。
8. **核查资料来源**：为每个关键论断找至少一个可访问、可核查的来源链接；无法核查的说法要么删掉，要么标注"未核实"。
9. **组织成 HTML**：按下文输出结构渲染为单文件 HTML 页面，保存到 `learning-materials/` 目录。

## 输出结构

生成的每个 HTML 文件必须包含以下章节（顺序固定，便于跨概念对比）：

1. 一句话个人解释（用自己的话，不含来源原句）
2. 学习目标
3. 核心问题（并标注对应章节）
4. 概念定义与边界（是什么 / 不是什么）
5. 核心机制或组成（可配 SVG 图示或 Mermaid 图）
6. 应用案例（具体场景 + 概念如何发挥作用）
7. 易混淆问题与使用边界
8. 自测题（附要点提示）
9. 参考来源（带链接，注明每个来源支撑了哪些论断）

除单份材料外，若一次学习多个概念，应另外生成或更新 `concept-relationship.md`：
用文字、表格和 Mermaid 图说明这些概念之间的关系（谁依赖谁、谁约束谁、如何配合工作）。

## 资料来源要求

- **禁止伪造来源**：只给出确实存在、可直接访问的 URL；不确定的链接先核实再写，核实不了就不写。
- 优先使用一手来源（官方文档、论文、技术博客原文），其次才是百科和二手解读。
- 每条来源须注明它支撑的具体论断，不允许"参考资料：随便列一堆"。
- 概念解释必须用自己的话重新组织，**不得整段照搬**任何来源或 AI 对话结果；引用原文须用引号并标注出处。

## 自检要求

生成完成后，逐项自检，任何一项不通过就修改后再交付：

- [ ] 定义句是自己组织语言写的，与任何来源原文重合度低（无连续照搬句子）；
- [ ] 全部核心问题都被正文回答，且能在正文里找到对应位置；
- [ ] 应用案例具体可走通（能顺着讲一遍流程，而不是泛泛而谈）；
- [ ] 至少列出一个易混淆概念及其区别标准；
- [ ] 自测题覆盖核心机制与易混淆点，附了要点提示；
- [ ] 每个关键论断都有可核查的来源链接，链接均真实可访问；
- [ ] HTML 章节顺序与输出结构一致，标题清晰可导航。

## 使用示例

调用方式（在 WorkBuddy 中）：

> 使用项目级 Skill「concept-learning-kit」，学习概念"检索增强生成（RAG）"，深度"入门+机制"。

生成结果：

```
learning-materials/rag.html   # 一份含 9 个章节的完整学习资料
```
